# Billetera virtual
Proyecto de la materia Taller de lenguajes II donde se diseñó y creó una billetera virtual de criptomonedas. El proyecto se dividió en las siguientes entregas:


Entregable 1: Diagrama UML, diagrama de secuencias y un javadoc a partir de 4 clases hechas en java.

Entregable 2: Base de datos usando SQLite. Aplicación del patrón DAO. Uso de API JDBC.

Entregable 3: Interfaz gráfica con librería Swing. Aplicación del modelo MVC y concurrencia (threads).
